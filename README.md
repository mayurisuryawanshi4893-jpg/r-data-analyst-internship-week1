# Week 1 - R Data Cleaning and Preliminary Analysis

## Dataset
IBM Telco Customer Churn dataset.

Source:
https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

## Work completed
- Dataset inspection
- Missing-value handling
- Duplicate check
- Data type conversion
- Categorical-variable conversion
- IQR-based outlier detection
- Min-max normalization
- Binary encoding of churn
- Descriptive statistics
- Churn and contract analysis
- Correlation analysis
- Visualizations

## Files
- `telco_week1_analysis.R` - R analysis script
- `Week1_Telco_Data_Analysis_Report.docx` - final report
- PNG files - analysis visualizations
